# bungalow.games

Bungalow Studios' site, served by GitHub Pages at https://bungalow.games.

- `turbotide/index.html`: TurboTide's one-link page at https://bungalow.games/turbotide (the address in the TikTok and Instagram bios). Each bio links with its own tag (`?s=tiktok`, `?s=ig`) and the page hands the visitor a store link carrying that tag, so App Store Connect, Play Console and Steamworks report downloads by source. Without a tag the page recognises Instagram's and TikTok's in-app browsers (user agent, referrer), so the bios can carry the plain address. Constants at the top of its script: `PT` (Apple provider token, set), `NAMES` (tag to campaign name: tiktok, instagram, bungalow_page), `PLAY` (Play listing URL), `STEAM` (Steam page URL).
- `turbotide/water_portrait.mp4` (720x1280, 30 fps, 5.2 s seamless loop, 2.2 MB) and `water_portrait_poster.jpg` (its first frame): the water behind the page, one tall shot rendered in the game (logo about 44% of the frame width, ending 33% down; three riders cross under it once per loop). Phones fill the height with it; windows squarer than 4:5 fit it whole, with a blurred copy of the poster filling the sides. The logo on the page is the one in the video. Change a video = give it a new name (GitHub Pages caches the page for 10 minutes). Source and render notes: `/mnt/project-files/bungalow-site/`.
- `turbotide/fonts/`: the game's fonts, Knewave (headings), Kanit ExtraBold Italic (the HUD font: buttons) and Saira (SIL Open Font License, licenses alongside). The page is drawn in the game's Chrome TV menu style (`docs/menus/chrome_tv/README.md` in the game's repo): logo lettering for the big words, chrome cap buttons that press in, orange labels.
- `index.html` (root): sends visitors to `/turbotide/`, keeping the `?s=` tag. It becomes the studio page when a second game arrives (each game in its own folder).
- `CNAME`: the custom domain for GitHub Pages. Keep it.

Counting (Nov 2, Alex's ask): the page loads PostHog (project TurboTide, same key as the game) cookieless: persistence in memory, no autocapture, no recording; it sends `$pageview` and `bio_cta_tap` {button: ios|android|steam|tiktok|instagram, href} with super properties site, page, source (tiktok | instagram | bungalow_page), tagged. A page with visits but no taps is the page's problem. Ad blockers hide some visitors. The privacy policy's website paragraph covers it.

- `race/` (Nov 13 2026, Alex: ghost links live on the studio's site): the page a TurboTide "race my ghost" link opens (`https://bungalow.games/race/#<run>`). A phone with the game opens the game instead; without it the page sends the friend to their store (`PLAY_STORE` in its script is empty until the Android game is public).
- `.well-known/apple-app-site-association` (iPhone) and `.well-known/assetlinks.json` (Android, the Play app-signing key's fingerprint): they let /race/ links open the game. Never delete or rename them. `.nojekyll` makes GitHub Pages serve that folder.
